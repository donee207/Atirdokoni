# Aroma&Style — atir va erkaklar kiyimi do‘koni

Oddiy statik sayt (HTML + JavaScript). Server yoki o‘rnatish kerak emas.

## GitHub Pages orqali ishga tushirish
1. github.com da **New repository** bosing, nomi masalan `aromastyle`, **Public**.
2. **Add file → Upload files**: `index.html`, `.nojekyll` va `images` papkasini tashlang, **Commit changes**.
3. **Settings → Pages → Source: Deploy from a branch**, branch `main`, papka `/ (root)`, **Save**.
4. 1–2 daqiqadan keyin havola: `https://FOYDALANUVCHI.github.io/aromastyle/`

## Mahsulotlarni o‘zgartirish
`index.html` ichida `const P=[` qismida kiyimlar, `const ATIR=` qismida atirlar ro‘yxati bor. Rasmlar `images/` papkasida.
